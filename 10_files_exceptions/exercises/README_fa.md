# تمرین‌های فصل ۱۰ — Files & Exceptions

## اهداف تمرین‌ها

این تمرین‌ها برای تثبیت مفاهیم زیر طراحی شده‌اند:

- نوشتن و خواندن فایل با `with open()`
- خواندن خط‌به‌خط فایل
- مدیریت خطا با `try-except`
- تبدیل داده و نادیده گرفتن ورودی نامعتبر
- کار با فایل CSV

## تمرین‌ها

| شماره | عنوان | مفهوم اصلی |
|---|---|---|
| ۱۰.۱ | نوشتن و خواندن فایل | `with open()`, `write()`, `read()` |
| ۱۰.۲ | خواندن خط‌به‌خط | `for line in file`, `enumerate` |
| ۱۰.۳ | مدیریت خطا | `try-except FileNotFoundError` |
| ۱۰.۴ | خواندن اعداد | `int()` در `try-except`, نادیده گرفتن خطا |
| ۱۰.۵ | CSV ساده | `csv.writer`, `csv.DictReader` |

## نکات کلیدی

- [فارسی] `with open("file.txt", "w")` فایل را می‌سازد یا بازنویسی می‌کند.
- [فارسی] `"r"` برای خواندن، `"w"` برای نوشتن، `"a"` برای افزودن.
- [فارسی] `file.read()` کل فایل را می‌خواند؛ `for line in file` خط‌به‌خط.
- [فارسی] `try-except` برای گرفتن خطای فایل ناموجود.
- [فارسی] `csv.DictReader` هر ردیف را به dict تبدیل می‌کند — دسترسی با نام ستون.

## خروجی مورد انتظار

برنامه فایل‌های `test.txt`, `numbers.txt`, `people.csv` را می‌سازد و خروجی شامل محتوای فایل‌ها، مجموع اعداد معتبر، و ردیف‌های CSV است.
