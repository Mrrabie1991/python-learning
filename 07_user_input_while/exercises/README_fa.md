# تمرین‌های فصل ۰۷ — User Input & while Loops

## اهداف تمرین‌ها

این تمرین‌ها برای تثبیت مفاهیم زیر طراحی شده‌اند:

- دریافت ورودی از کاربر با `input()`
- حلقه `while True` با `break`
- اعتبارسنجی ورودی با `try-except`
- جمع‌آوری آیتم‌ها تا رسیدن به مقدار sentinel
- ساخت منوی تعاملی با توابع جداگانه

## تمرین‌ها

| شماره | عنوان | مفهوم اصلی |
|---|---|---|
| ۷.۱ | جمع اعداد | `while True` + `break` |
| ۷.۲ | حدس عدد | شرط‌های راهنمایی در حلقه |
| ۷.۳ | اعتبارسنجی ورودی | `try-except ValueError` |
| ۷.۴ | جمع‌آوری آیتم‌ها | Sentinel pattern با `enumerate` |
| ۷.۵ | منوی تعاملی | توابع جداگانه + حلقه منو |

## نکات کلیدی

- الگوی استاندارد اعتبارسنجی: `while True` + `break` بعد از ورودی معتبر.
- `input()` همیشه رشته برمی‌گرداند — برای عدد باید `int()` یا `float()` تبدیل کنی.
- `try-except` برای گرفتن ورودی غیرعددی.
- Sentinel pattern: یک مقدار خاص (مثل `"done"` یا `"back"`) برای خروج از حلقه.
- جدا کردن منطق هر گزینه در تابع خودش، خوانایی را بالا می‌برد.

## خروجی مورد انتظار

برنامه تمام بخش‌ها را اجرا می‌کند و خروجی شامل مجموع اعداد، نتیجه حدس، ورودی معتبر، لیست آیتم‌ها، و عملکرد منو است.
