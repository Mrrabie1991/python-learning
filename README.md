# Python Learning

From C++ to Pythonic: An experienced engineer's journey to master Python.

## About This Repository

This repository documents my structured transition from Modern C++ (11+ years) to Python, with a focus on Intelligent Systems Engineering.

The learning path follows a comparison-based approach: every Python concept is taught in contrast with its C++ equivalent.

## What's Inside

- **13 chapters** covering Python from fundamentals to advanced topics
- **Exercises** for each chapter
- **Mini-project:** Sensor Data Analyzer (CLI tool for industrial sensor data analysis)
- Each chapter includes bilingual documentation (English + Persian)

## Mini-Project

### Sensor Data Analyzer

A CLI tool for analyzing industrial sensor data from CSV files. Built with:

- `dataclass`, `@property`, Type Hints
- `csv.DictReader`, `with open()`
- `pytest` (11 tests)
- Package structure (`src/`, `pyproject.toml`)

## Learning Approach

- **Comparison-based:** Every concept is taught with its C++ equivalent
- **Deep over speed:** Understanding "why" before "how"
- **Bilingual documentation:** English for GitHub, Persian for personal notes
- **Project-driven:** Each phase ends with a real project
