# تمرین‌های فصل ۰۵ — if Statements

## اهداف تمرین‌ها

این تمرین‌ها برای تثبیت مفاهیم زیر طراحی شده‌اند:

- ساختار `if` / `elif` / `else`
- `match-case` و الگوهای نگهبان (guard patterns)
- مقادیر truthy و falsy
- عملگر سه‌تایی (ternary operator)
- حل مسئله منطقی (سال کبیسه)

## تمرین‌ها

| شماره | عنوان | مفهوم اصلی |
|---|---|---|
| ۵.۱ | شرط ساده | `if` / `elif` / `else` |
| ۵.۲ | نمره‌دهی | `if-elif-else` و `match-case` با guard |
| ۵.۳ | بررسی truthy/falsy | `if not input` |
| ۵.۴ | عملگر سه‌تایی | `value_if_true if condition else value_if_false` |
| ۵.۵ | سال کبیسه | منطق ترکیبی با `and` / `or` |

## نکات کلیدی

- `match-case` با `case s if s >= 90:` یک متغیر جدید `s` می‌سازد که مقدار `match` را می‌گیرد.
- برای شرط‌های مقایسه‌ای ساده، `if-elif-else` خواناتر از `match-case` است.
- رشته خالی (`""`) و لیست خالی (`[]`) و `None` مقادیر falsy هستند.
- عملگر سه‌تایی: `result = "Yes" if condition else "No"`.
- سال کبیسه: `(year % 400 == 0) or (year % 4 == 0 and year % 100 != 0)`.

## خروجی مورد انتظار

برنامه از کاربر ورودی می‌گیرد و نتایج شرط‌ها را چاپ می‌کند. برای هر بخش، ورودی‌های مختلف را تست کنید.
