# ۰۲ - متغیرها و انواع داده ساده

## مدل متغیر در پایتون: Name Binding

در C++، متغیر مانند جعبه‌ای با اندازه و نوع ثابت است (Box Model).
در پایتون، متغیر نامی است که به یک شیء در حافظه اشاره می‌کند (Name Binding / Sticky Note Model).

### مقایسه مدل متغیر

| ویژگی | C++ | Python |
|---|---|---|
| مدل | Box Model (جعبه) | Name Binding (برچسب) |
| نوع (Type) | متعلق به متغیر است | متعلق به شیء است |
| اندازه حافظه | در زمان کامپایل مشخص | توسط شیء در زمان اجرا تعیین |
| تغییر نوع | مجاز نیست | مجاز است (Dynamic Typing) |
| عملگر = | مقدار را در جعبه کپی می‌کند | نام را به شیء جدید متصل می‌کند (Rebinding) |

### ابزارهای بازرسی: type() و id()

```python
x = 5
print(type(x))  # <class 'int'> — نوع شیء
print(id(x))    # 140735000123456 — آدرس حافظه شیء (معادل & در C++)
```

### مثال: Rebinding

```python
x = 5           # x به یک شیء int با مقدار ۵ اشاره می‌کند
x = "Hello"     # x از شیء int جدا شده و به یک شیء str جدید متصل می‌شود
x = [1, 2, 3]   # x اکنون به یک شیء list اشاره می‌کند
```

در C++، یک متغیر `int` نمی‌تواند رشته یا آرایه را در خود نگه دارد. در پایتون، نام می‌تواند به هر شیئی اشاره کند.

## Garbage Collection — سرنوشت اشیاء بی‌صاحب

وقتی نام از شیئی جدا می‌شود و هیچ نام دیگری به آن شیء اشاره نمی‌کند، شیء به حالت unreferenced درمی‌آید.
Garbage Collector (GC) پایتون به صورت خودکار این اشیاء را در زمان نامشخصی از حافظه پاک می‌کند.
برخلاف C++، نیازی به `delete` دستی نیست.

```python
x = 5       # شیء int(5) ساخته می‌شود
x = "Hello" # شیء int(5) بی‌صاحب می‌شود و GC آن را جمع‌آوری می‌کند
```

## انواع داده‌های ساده (Simple Data Types)

### int — عدد صحیح با دقت نامحدود

برخلاف C++ که `int` معمولاً ۴ بایت و محدوده ثابت دارد، `int` در پایتون دقت نامحدود دارد.

```python
big = 2 ** 100  # 2^100 — در C++ سرریز می‌شود، در پایتون نه
print(big)      # 1267650600228229401496703205376
```

### float — عدد اعشاری

پایتون فقط یک نوع `float` با دقت ۶۴ بیتی (معادل `double` در C++) دارد. نوع ۳۲ بیتی جداگانه وجود ندارد (در پایتون خام).

```python
pi = 3.141592653589793
print(f"Type: {type(pi)}")  # <class 'float'>
```

### str — رشته

`str` در پایتون:
- به صورت پیش‌فرض Unicode است.
- immutable است (پس از ساخته شدن، محتوایش قابل تغییر نیست).

```python
s = "Hello Python"
print(s[0])     # H — ایندکس‌پذیر است
# s[0] = "h"    # خطا — str immutable است
```

### bool — مقدار بولی

`bool` در پایتون زیرکلاس `int` است (`True == 1`, `False == 0`).

```python
print(True + True)   # 2
print(bool(0))       # False
print(bool("Hello")) # True
```

### None — شیء هیچ

`None` معادل `nullptr` در C++ است. یک شیء singleton از نوع `NoneType`.

```python
x = None
print(x is None)  # True
```

## تبدیل نوع (Type Conversion)

```python
int("42")       # 42
float("3.14")   # 3.14
str(100)        # "100"
int(3.99)       # 3 — truncate می‌کند، round نمی‌کند
```

## Immutable و Mutable

- **Immutable:** `int`, `float`, `str`, `bool`, `NoneType`, `tuple`
- **Mutable:** `list`, `dict`, `set`

Immutable/Mutable ویژگی خود شیء است، نه نام. نام همیشه می‌تواند به شیء جدید اشاره کند (Rebinding).

```python
s = "Hello"     # str — immutable
s = 5           # rebinding مجاز است (نام تغییر مقصد داد)
# اما s[0] = "h" غیرمجاز است (محتوای str قابل تغییر نیست)
```

## پرسش و پاسخ (Q&A)

### سوال: وقتی x = 5 و سپس x = "Hello" نوشته می‌شود، شیء ۵ چه می‌شود؟
**پاسخ:** شیء int(5) بی‌صاحب می‌شود. Garbage Collector پایتون در زمانی نامشخص آن را از حافظه پاک می‌کند. نیازی به مدیریت دستی حافظه نیست.

### سوال: Immutable ویژگی نام است یا شیء؟
**پاسخ:** Immutable ویژگی خود شیء است. نام همیشه می‌تواند rebind شود (به شیء جدید اشاره کند). Immutable یعنی محتوای داخلی شیء قابل تغییر نیست (مثلاً نمی‌توان یک کاراکتر از str را تغییر داد).

### سوال: آیا Python مثل C++ دارای float و double جداگانه است؟
**پاسخ:** خیر. در پایتون فقط یک نوع float با دقت ۶۴ بیتی (معادل double در C++) وجود دارد. کتابخانه‌های خارجی مانند NumPy انواع ۳۲ بیتی را فراهم می‌کنند.

### سوال: تفاوت `is` و `==` در پایتون چیست؟
**پاسخ:** `==` مقادیر را مقایسه می‌کند (equality). `is` هویت اشیاء را مقایسه می‌کند (identity) — آیا هر دو نام به یک شیء اشاره می‌کنند؟

```python
a = [1, 2]
b = [1, 2]
print(a == b)  # True — مقادیر یکسان
print(a is b)  # False — دو شیء متفاوت
```

### سوال: `type()` و `id()` چه کاربردی دارند؟
**پاسخ:** `type(x)` نوع شیء را برمی‌گرداند. `id(x)` آدرس حافظه شیء را نشان می‌دهد و معادل عملگر `&` در C++ است. این دو ابزار اصلی برای بازرسی و اشکال‌زدایی اشیاء در پایتون هستند.
