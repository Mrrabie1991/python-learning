# تمرین‌های فصل ۰۲ — Variables & Simple Data Types

## اهداف تمرین‌ها

این تمرین‌ها برای تثبیت مفاهیم زیر طراحی شده‌اند:

- انواع داده ساده (`int`, `float`, `str`, `bool`, `None`)
- مدل Name Binding (نام‌ها به اشیاء اشاره می‌کنند، نه جعبه‌های حافظه)
- مفهوم Immutable بودن
- تفاوت `is` و `==`
- Integer caching در CPython

## تمرین‌ها

| شماره | عنوان | مفهوم اصلی |
|---|---|---|
| ۲.۱ | کاوش در انواع داده | `type()` و `id()` |
| ۲.۲ | تبدیل نوع | `int()`, `float()`, `str()` |
| ۲.۳ | Immutable بودن | تلاش برای تغییر `int` و `str` |
| ۲.۴ | `is` vs `==` | مقایسه هویت و مقدار |
| ۲.۵ | تحلیل حافظه | Integer caching |

## نکات کلیدی

- `type(x)` نوع شیء را برمی‌گرداند.
- `id(x)` آدرس حافظه شیء را نشان می‌دهد.
- `int(3.99)` قسمت اعشاری را حذف می‌کند (truncate)، نه گرد کردن.
- اعداد ۵- تا ۲۵۶ در CPython کش می‌شوند — `x = 5` و `y = 5` به یک شیء اشاره می‌کنند.
- `==` مقدار را مقایسه می‌کند، `is` هویت را.
