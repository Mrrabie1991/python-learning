# تمرین‌های فصل ۰۸ — Functions

## اهداف تمرین‌ها

این تمرین‌ها برای تثبیت مفاهیم زیر طراحی شده‌اند:

- تعریف توابع با `def` و پارامترهای پیش‌فرض
- بازگرداندن مقدار با `return`
- آرگومان‌های متغیر با `*args` و `**kwargs`
- توابع بی‌نام با `lambda`
- مدیریت خطا در توابع

## تمرین‌ها

| شماره | عنوان | مفهوم اصلی |
|---|---|---|
| ۸.۱ | توابع ساده | `def`, پارامتر پیش‌فرض |
| ۸.۲ | پارامتر و بازگشت | `return`, شرط ساده |
| ۸.۳ | `*args` و `**kwargs` | آرگومان‌های متغیر |
| ۸.۴ | Lambda | توابع بی‌نام، `sorted` با `key` |
| ۸.۵ | ماشین حساب | انتخاب عملیات، مدیریت تقسیم بر صفر |

## نکات کلیدی

- پارامتر پیش‌فرض: `def greet(name, greeting="Hello")`.
- `*args` یک tuple از آرگومان‌های positional می‌سازد.
- `**kwargs` یک dict از آرگومان‌های keyword می‌سازد.
- `sorted(points, key=lambda p: p[1])` بر اساس عنصر دوم tuple مرتب می‌کند.
- مدیریت تقسیم بر صفر: قبل از تقسیم، `if b == 0` را چک کن.

## خروجی مورد انتظار

برنامه تمام بخش‌ها را اجرا می‌کند و خروجی شامل نتایج توابع، مرتب‌سازی lambda، و عملکرد ماشین حساب است.
