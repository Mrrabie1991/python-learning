# تمرین‌های فصل ۰۴ — Working with Lists

## اهداف تمرین‌ها

این تمرین‌ها برای تثبیت مفاهیم زیر طراحی شده‌اند:

- حلقه `for` و `enumerate` برای پیمایش لیست
- List Comprehension برای ساخت و فیلتر لیست
- کار با `tuple` و unpacking
- ابزارهای ترکیب داده (`zip`)
- تحلیل ساده داده با حلقه و comprehension

## تمرین‌ها

| شماره | عنوان | مفهوم اصلی |
|---|---|---|
| ۴.۱ | پیمایش و تبدیل لیست | `for`, `enumerate`, `lower()` |
| ۴.۲ | List Comprehension پایه | `[expr for x in list if cond]` |
| ۴.۳ | کار با tuple | unpacking، swap بدون متغیر موقت |
| ۴.۴ | zip و enumerate | جفت‌کردن داده‌ها |
| ۴.۵ | تحلیل داده ساده | فیلتر، میانگین، یافتن max/min با حلقه |

## نکات کلیدی

- Unpacking با `*` فقط در آرگومان‌های تابع مجاز است، نه داخل f-string.
- `sorted(list)` لیست اصلی را تغییر نمی‌دهد؛ `list.sort()` تغییر می‌دهد.
- `zip` با لیست‌های با طول متفاوت، تا کوتاه‌ترین لیست کار می‌کند.
- جابجایی دو متغیر در پایتون: `a, b = b, a`.
- برای یافتن max/min با حلقه، مقدار اولیه را از عنصر اول لیست بگیر.
