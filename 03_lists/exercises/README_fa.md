# تمرین‌های فصل ۰۳ — Introducing Lists

## اهداف تمرین‌ها

این تمرین‌ها برای تثبیت مفاهیم زیر طراحی شده‌اند:

- ساخت و دستکاری لیست (`append`, `insert`, `remove`, `pop`, `del`)
- ایندکس‌گذاری مثبت و منفی
- Slicing با `[start:stop:step]`
- تفاوت Shallow Copy و Deep Copy
- List Comprehension و کار با ماتریس
- ابزارهای پیمایش (`zip`, unpacking با `*`)

## تمرین‌ها

| شماره | عنوان | مفهوم اصلی |
|---|---|---|
| ۳.۱ | کار با لیست پایه | `append`, `insert`, `len`, ایندکس منفی |
| ۳.۲ | حذف از لیست | `remove`, `pop`, `del` |
| ۳.۳ | Slicing | برش لیست با گام‌های مختلف |
| ۳.۴ | کپی سطحی و عمیق | تفاوت `copy()` و `deepcopy()` |
| ۳.۵ | ماتریس با List Comprehension | ساخت ماتریس، قطر اصلی، transpose |

## نکات کلیدی

- `list(range(10))` اعداد ۰ تا ۹ را می‌سازد، نه ۱ تا ۱۰.
- `*row` در `print` لیست را بدون براکت و کاما چاپ می‌کند.
- `zip(*matrix)` ترانهاده ماتریس را می‌سازد — خروجی tuple است، با `list()` تبدیل می‌شود.
- Shallow Copy فقط لایه اول را کپی می‌کند — لایه‌های داخلی مشترک می‌مانند.
- Deep Copy همه لایه‌ها را از نو می‌سازد.
