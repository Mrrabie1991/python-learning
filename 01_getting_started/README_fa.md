# ۰۱ - شروع کار و فلسفه پایتون

## پایتون چیست؟

پایتون یک زبان برنامه‌نویسی همه‌منظوره، سطح بالا، و مفسری (Interpreted) است که توسط Guido van Rossum در سال ۱۹۹۱ ساخته شد. هدف اصلی آن سادگی، خوانایی، و افزایش سرعت توسعه است.

## مفسر (Interpreter) در برابر کامپایلر (Compiler)

### مدل C++ (کامپایلری)

کد منبع (.cpp) -> کامپایلر -> کد ماشین -> اجرا

- کل کد یکباره به زبان ماشین ترجمه می‌شود.
- خطاها قبل از اجرا (Compile-time) پیدا می‌شوند.
- نیاز به Build System دارد (CMake, Make).
- سرعت اجرا بسیار بالاست.

### مدل Python (مفسری)

کد منبع (.py) -> مفسر Python -> خط به خط اجرا

- کد خط به خط خوانده و اجرا می‌شود.
- خطاها در زمان اجرا (Runtime) پیدا می‌شوند.
- بدون نیاز به Build — تغییر بده، اجرا کن.
- سرعت توسعه بسیار بالاست.

**تشبیه:** مفسر مثل یک مترجم همزمان است که جمله به جمله ترجمه می‌کند. کامپایلر مثل مترجمی است که کل کتاب را یکباره ترجمه کرده و تحویل می‌دهد.

## The Zen of Python — فلسفه پایتون

با دستور زیر قابل مشاهده است:

```bash
python -c "import this"
```

اصول کلیدی:

- **Beautiful is better than ugly.** — کد باید زیبا باشد.
- **Explicit is better than implicit.** — صریح بنویس، نه پنهان.
- **Simple is better than complex.** — سادگی را انتخاب کن.
- **Readability counts.** — خوانایی مهم است.
- **There should be one-- and preferably only one --obvious way to do it.** — برای هر کار، یک راه روشن وجود داشته باشد.

### Pythonic یعنی چه؟

کدی که با اصول فوق هماهنگ باشد. کدی که انگار "متولد پایتون" است، نه ترجمه‌شده از زبانی دیگر.

## اولین برنامه — hello_world.py

### کد

```python
import sys
import platform

def main():
    print("Hello, Intelligent Systems!")
    print(f"Python version: {sys.version}")
    print(f"Running on: {platform.system()} {platform.release()}")

if __name__ == "__main__":
    main()
```

### دستور اجرا

```bash
python hello_world.py
```

### خروجی نمونه
```bash
Hello, Intelligent Systems!
Python version: 3.14.6 (main, ...)
Running on: Windows 11
```
### نکته مهندسی:
```bash 
    if __name__ == "__main__"
```
این ساختار تضمین می‌کند که تابع main() فقط زمانی اجرا شود که فایل مستقیماً اجرا شده باشد، نه وقتی که به عنوان ماژول import شده باشد. (معادل int main() در C++)

## پرسش و پاسخ (Q&A)

### سوال: مفسر دقیقاً چه فرقی با کامپایلر داره؟ آیا مثل یه مترجمه؟

**پاسخ:** دقیقاً. مفسر مثل مترجم همزمانه — خط به خط می‌خونه و اجرا می‌کنه. کامپایلر کل برنامه رو یه‌باره به زبان ماشین ترجمه می‌کنه و فایل اجرایی می‌سازه. در پایتون، خبری از Build کردن و فایل‌های obj. و link کردن نیست. تغییر می‌دی، اجرا می‌کنی.

### سوال: Pythonic یعنی چی؟

**پاسخ:** یعنی کدی بنویسی که با فلسفه پایتون (The Zen of Python) هماهنگ باشه: خوانا، ساده، صریح. کدی که انگار یه پایتون‌کار نوشته، نه کسی که C++ رو توی پایتون ترجمه کرده.
