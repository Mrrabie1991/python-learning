# تمرین‌های فصل ۰۶ — Dictionaries

## اهداف تمرین‌ها

این تمرین‌ها برای تثبیت مفاهیم زیر طراحی شده‌اند:

- ساخت و دسترسی به `dict`
- افزودن، تغییر، و حذف کلید-مقدار
- پیمایش `dict` با `keys()`, `values()`, `items()`
- `dict comprehension`
- شمارش عناصر با `dict`

## تمرین‌ها

| شماره | عنوان | مفهوم اصلی |
|---|---|---|
| ۶.۱ | ساخت و دسترسی | `[]`, `get()`, مقدار پیش‌فرض |
| ۶.۲ | افزودن و حذف | `del`, `pop()` |
| ۶.۳ | پیمایش | `keys()`, `values()`, `items()`, میانگین |
| ۶.۴ | Dict Comprehension | ساخت و فیلتر dict |
| ۶.۵ | شمارش کلمات | الگوی شمارش با `get(word, 0) + 1` |

## نکات کلیدی

- `d.get(key, default)` امن‌تر از `d[key]` است — اگر کلید نباشد، به‌جای خطا، `default` را برمی‌گرداند.
- `del d[key]` فقط حذف می‌کند؛ `d.pop(key)` حذف می‌کند و مقدار را برمی‌گرداند.
- برای شمارش عناصر: `d[word] = d.get(word, 0) + 1`.
- `dict comprehension`: `{k: v for k, v in items if condition}`.
- تعویض کلید و مقدار: `{v: k for k, v in d.items()}`.

## خروجی مورد انتظار

برنامه تمام بخش‌ها را اجرا می‌کند و خروجی شامل dictهای ساخته‌شده، مقادیر پیمایش‌شده، و نتایج شمارش است.
